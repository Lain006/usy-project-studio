# 办公界面与动效更新

日期：2026-11-09。模式：Operate。范围：现有三页视觉及状态反馈，保留数据、存储契约、项目表单和任务操作。

## 设计与实施

- 使用 design-taste-frontend、emil-design-eng、impeccable；按 project-workflow 的规格、实施、验证流程执行。
- 选择 Achromatic ledger，seed 1297954870，无重抽。保留现有三页信息架构与中文系统字体；采用浅灰工作空间、白色内容、近黑主按钮、蓝色进度。现有校徽是品牌资产，保留其原色。
- 保留已有顶栏作为当前位置，增加底部真实存储状态；这是既有办公外壳细化，不照搬抽取的首页问候语布局。
- 首页回答“哪些教学任务还未完成”；项目页回答“我要进入哪个项目”；任务页回答“当前项目接下来做什么”。
- 两个既有课程项目、四个任务来自原始数据，不增加示例记录。数量、进度、待办均从共享 projects 计算。
- 识别元素为原校徽、USY Studio 名称、课程名、项目目录与任务进度；无虚构用户、通知、在线人数或同步状态。
- 统一 @ant-design/icons 线性图标。保存状态区分示例、已读取、已保存、失败、读取受阻。
- 动效重点：任务勾选带动进度条变化（transform 220ms）；按钮按压 120ms；弹层短时出现。列表及整页不做入场编排，键盘输入与减少动态效果模式取消位移动效。
- 固定数据先验证布局，继续复用当前项目与任务状态。主进程、预加载、数据结构与原始数据不变，不新增依赖。

## 验收标准

- 构建及 lint 通过；三页、创建项目、任务新增/完成/删除、切换项目、本地保存行为保持。
- 1440、768、390px 检查，手机宽度导航横排，内容不横向溢出；长名称、空项目、空任务和错误状态可读。
- 保存失败不显示已保存；损坏存储继续阻止编辑；隔离浏览器验证，不改用户已保存数据。
- 鼠标、键盘、焦点、减少动态效果检查；截图记录旧版与新版。
- 备份：docs/backups/2026-11-09-office-ui；检查证据：docs/evidence/office-ui 与 .taste-skill。

## 最终复核

| Before | After | Why |
| --- | --- | --- |
| 深色固定侧栏、亮蓝选中块 | 浅灰侧栏、中性选中态、统一线性图标 | 将注意力留给项目与任务 |
| 四个独立统计卡与较高的完成率面板 | 一组分隔统计、紧凑的总体进度 | 首屏可看到完整项目概况与待办 |
| 渐变且持续流动的任务进度 | 单色进度，数据变化时 transform 220ms | 进度只在操作后反馈，避免持续分心 |
| 无保存状态栏 | 示例、已读取、已保存、失败、读取受阻五种状态 | 用户可判断本次修改是否已经保存 |
| 仅桌面固定导航、无 viewport | 桌面侧栏、窄窗口横排导航，390px 可用 | 避免窄窗口被侧栏挤压 |
| 默认字体栈 | Microsoft YaHei UI 优先的本机字体栈 | 明确中文办公界面的字体选择 |

视觉复核（应用界面的七项问题）：

1. 首页以真实数量和任务进度回答当前工作状况；最近项目和待办同在桌面首屏。窄窗口将待办提前。
2. 内容左右边缘统一；桌面两个信息面板按实际内容自然结束，不为齐底添加占位。只有两个项目时项目页留白保留，不虚构数据填满页面。
3. 进度蓝用于数据；成功绿用于完成标记，异常色用于存储错误。导航与主操作采用中性色；原校徽作为既有品牌资产保留。
4. 统计、进度、待办、状态栏均读取同一份 projects。浏览器和 Electron 交互验证勾选后 50% → 75%，重启后仍为 75%。
5. 空项目显示 0，空任务显示 0%；读取异常暂停编辑，不用虚假的“已保存”掩盖错误。
6. 无图例或新增业务图表；进度始终有百分比，项目有已完成/总任务文字。
7. 390px 导航横排，长项目名与长任务文本换行，页面不横向溢出。长文本会增加页面高度，内容可滚动查看。

最终首页 inspect：1440、768、390px 共 0 FAIL、0 WARN；Impeccable detect 返回空数组。Taste lint 0 FAIL、2 WARN，两处均为 `box-shadow: none` 被正则误报，实际界面无静止卡片阴影。完整检查记录见 VERIFICATION.md。

没有引入照片、视频或新示例数据。继续使用原校徽及原“金融数据上链存证系统”“智能合约开发项目”课程数据；用户保存的数据加载规则不变。


## 2026-11-12：任务优先的紧凑界面（当前方案）

依据用户明确确认的 UI 方案实施，使用 frontend-design、emil-design-eng、impeccable，并沿用 project-workflow。模式仍为 Operate。以下约定取代上文关于自绘进度、重复顶栏与全局按压动画的描述。

- 视觉延续浅灰背景、白色内容、深灰主按钮、蓝色进度和绿色完成标记；中文系统字体，页面标题 22px。保留校徽、三页导航和原课程数据。
- 删除独立重复顶栏，首页四项 Statistic 与总体 Progress 合并为紧凑概览，待办先于最近项目。桌面双列，1100px 以下纵向排列；项目卡片 600px 以下单列。
- ProgressMeter 仅封装 Ant Progress；数量使用 Badge，页标题使用 Typography.Title，状态栏使用 Layout.Footer。原生标签仅承载语义、布局或普通文本，不自绘业务控件。
- 任务页用项目选择器表达当前项目，摘要只保留课程、数量和进度。保留任务顺序，文本包含在 Checkbox 标签内；添加后焦点返回输入框。窄屏状态标签换到文字下方，长文字和删除操作从顶部对齐。
- 项目路径省略显示，用 Tooltip 在悬停或键盘聚焦时查看。无任务显示“尚未添加任务”；新建项目和未完成状态统一命名。任务页无项目时可调用既有创建弹窗。表单 scrollToFirstError 开启 focus。
- 移除自绘进度 transform 动画与全局按钮缩放，沿用 Ant 短反馈；保留键盘与减少动态效果的即时更新。
- 数据字段、存储键和版本、示例数据、主进程及 preload 未改；未新增依赖。Tasks 新增 onCreate 回调，复用 App 创建入口。

| Before | After | Why |
| --- | --- | --- |
| 自绘进度、统计和计数 | Ant Progress、Statistic、Badge | 满足教师组件要求 |
| 独立顶栏和重复标题 | 导航 + 单一页标题 | 释放默认窗口纵向空间 |
| 任务文字与复选框分离 | Checkbox 包含任务文字 | 扩大点击范围 |

| 全局按钮缩放和自绘动效 | Ant 原有反馈 | 减少覆盖和维护 |
